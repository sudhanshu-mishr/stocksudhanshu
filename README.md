# Mini Financial Data Platform 🚀

A full-stack, end-to-end Mini Financial Data Platform demonstrating data engineering, backend API development, and frontend visualization.

## 🎯 Features

- **Data Collection Pipeline:** Fetches 1 year of historical stock data using `yfinance` for a selection of companies (AAPL, MSFT, GOOGL, AMZN, TSLA).
- **Data Engineering:** Cleans missing values and enriches the dataset using Pandas (Daily Returns, 7-Day Moving Averages, 52-week High/Low, Volatility Scores).
- **Backend API:** FastAPI REST application with asynchronous endpoints serving SQLite data.
- **Frontend Dashboard:** Vanilla JS and HTML/CSS web app using Chart.js to visualize metrics, toggle date ranges, and compare stocks.
- **Bonus Feature (Machine Learning):** Simple Linear Regression model to forecast the next 7 days of closing prices.
- **Bonus Feature (Docker):** Contains a `Dockerfile` for quick environment setup and deployment.

## 🛠 Tech Stack

- **Backend:** Python, FastAPI, Uvicorn, SQLite
- **Data Processing:** Pandas, NumPy, yfinance, Scikit-Learn
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript, Chart.js
- **Containerization:** Docker

## 🚀 How to Run Locally

### Option 1: Using Python Environment

1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run Data Collection Pipeline:**
   This script fetches market data, cleans it, calculates metrics, and initializes `backend/financial_data.db`.
   ```bash
   python backend/data_service.py
   ```

3. **Start the FastAPI Server:**
   ```bash
   python backend/app.py
   # Or using uvicorn directly:
   # uvicorn backend.app:app --host 0.0.0.0 --port 8000
   ```

4. **View Dashboard:**
   Open your browser and navigate to `http://localhost:8000`

### Option 2: Using Docker

1. **Build the Image:**
   ```bash
   docker build -t findash:latest .
   ```

2. **Run the Container:**
   ```bash
   docker run -p 8000:8000 findash:latest
   ```

3. **View Dashboard:**
   Open your browser and navigate to `http://localhost:8000`

## 📖 API Documentation

The backend exposes several endpoints. When running the server, interactive API documentation is automatically generated by FastAPI at `http://localhost:8000/docs`.

### Core Endpoints

- `GET /api/companies` - Returns a list of all available company symbols.
- `GET /api/data/{symbol}?days=30` - Returns historical stock data and calculated metrics for the specified symbol.
- `GET /api/summary/{symbol}` - Returns a summary including 52-week High/Low, average close, and a custom volatility score.

### Bonus / Advanced Endpoints

- `GET /api/compare?symbol1=AAPL&symbol2=MSFT&days=30` - Compares the percentage change of two stocks over a timeframe.
- `GET /api/insights` - Returns the top gainers and losers based on the latest daily return.
- `GET /api/predict/{symbol}?days=7` - Uses Scikit-Learn (Linear Regression) to predict the closing price for the next N days.

## 💡 Creativity & Insights Added

- **Volatility Score:** Added a rolling 30-day standard deviation of daily returns to quantify risk. This is displayed on the frontend summary cards.
- **Market Insights:** A dedicated section on the dashboard highlighting Top Gainers and Top Losers.
- **Comparison Feature:** An endpoint and UI control allowing users to plot the normalized percentage change of two different stocks over time to directly compare relative performance.
- **Predictive ML:** A basic linear regression model leveraging historical data indices to forecast upcoming closing prices.

### Option 3: Deploy to Render ☁️

This repository is ready to be deployed as a single Web Service on Render.

**Using the Render Dashboard (Blueprint):**
1. Fork or push this repository to GitHub.
2. Log into Render and click **New+** -> **Blueprint**.
3. Connect your repository. Render will automatically read the `render.yaml` file and configure the service (installing dependencies, running the data pipeline, and starting the uvicorn server).

**Manual Setup on Render:**
1. Create a new **Web Service**.
2. Connect your repository.
3. Set the Environment to `Python 3`.
4. Set Build Command: `pip install -r requirements.txt && python backend/data_service.py`
5. Set Start Command: `uvicorn backend.app:app --host 0.0.0.0 --port $PORT`
6. Click Deploy!
